# 🏴‍☠️ Пиратские Алгоритмы

Браузерная 3D-игра на [Babylon.js](https://www.babylonjs.com/) для развития у детей навыков алгоритмического мышления — в духе «черепашки» / Lightbot.

## Идея

Ребёнок не управляет героем напрямую. Он **составляет программу** из команд:

- ⬆️ **Вперёд** — шаг на одну клетку
- ↪️ **Налево** — поворот на 90°
- ↩️ **Направо** — поворот на 90°

Потом нажимает **«Запустить»**, и герой по шагам исполняет алгоритм: **обходит пиратов** (красные кубы с коллайдерами), **собирает монеты и бусты** и **добегает до финиша** 🏁.

В начале можно выбрать героя — **Мишаню** 🧒 или **Алину** 👧.

## Запуск

GLB-модели нельзя грузить с `file://` (браузер заблокирует). Нужен локальный сервер:

```bash
npm start
```

Откроется на <http://localhost:5173>. Либо любой статический сервер:

```bash
python3 -m http.server 5173
# затем открыть http://localhost:5173
```

## Структура

```
index.html          — разметка, экраны, подключение Babylon.js (CDN)
css/style.css       — стили интерфейса
js/levels.js        — описание уровней (карты в виде ASCII-сеток)
js/game.js          — движок: сцена, загрузка моделей, сетка, исполнение алгоритма
js/ui.js            — связывает кнопки/панель с движком
assets/models/      — boy.glb, girl.glb, coin.glb, game_pirate_adventure_map.glb
```

## Как добавить уровень

В [js/levels.js](js/levels.js) добавь объект в массив `LEVELS`. Карта — массив строк:

| Символ | Значение            |
|--------|---------------------|
| `S`    | старт героя         |
| `F`    | финиш               |
| `#`    | пират (препятствие) |
| `C`    | монета (+1)         |
| `B`    | буст (+3)           |
| `.`    | свободная клетка    |

`startDir` — куда смотрит герой в начале: `"N"`, `"E"`, `"S"`, `"W"`.

## Что дальше (идеи)

- Живые модели пиратов вместо кубов (патрулирование по маршруту).
- Команда «цикл» (повторить N раз) — следующий уровень абстракции.
- Звук, частицы при сборе монет, таймер/звёзды за минимум команд.

## Настройка

Геометрия и тайминги вынесены в константы вверху [js/game.js](js/game.js):
`CELL`, `HERO_HEIGHT`, `MOVE_MS`, `TURN_MS`. Если доска висит слишком высоко
над островом — подправь вычисление `this.gridY` в методе `loadMap()`.
